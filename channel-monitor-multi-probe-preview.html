账号探针

每个探针是一套独立的 URL + API Key，可单独失败，不影响其他探针。

3 个探针状态按最新一次检测聚合
01账号探针 A正常 · 182ms
最近检测：刚刚可用
02账号探针 B异常 · 超时
最近检测：38 秒前等待下次重试
03账号探针 C正常 · 96ms
最近检测：12 秒前可用
监控最终状态正常 · 96ms

3 个探针中有 2 个可用，展示可用探针里的最低延迟。单个探针异常不会让整个分组误报不可用。

任一正常即为正常无正常但有降级则为降级全部失败才为不可用
